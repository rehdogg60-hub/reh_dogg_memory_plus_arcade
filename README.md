====================================
ABOUT THE GAME
====================================

Reh Dogg Memory Plus Arcade is a fast-paced neon arcade-style memory challenge inspired by classic retro cabinet games.

Flip cards, match pairs, beat the timer, and survive all 7 escalating arcade stages.

Built with the signature Reh Dogg Games Plus arcade atmosphere:
- Neon visuals
- Arcade energy
- Combo excitement
- Timer pressure
- Retro-inspired sound FX
- Mobile-friendly gameplay

====================================
HOW TO PLAY
====================================

Desktop:
- Open the HTML file in a modern browser
- Click cards using the mouse

Mobile:
- Tap cards on the screen
- Best played in landscape mode

Goal:
- Match all pairs before the timer reaches zero
